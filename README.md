# NORTHLINE 服务介绍

## 面向长期服务支付的美国本地虚拟卡

NORTHLINE 提供用于固定线上服务支付的美国本地商户绑定虚拟卡。完成订单后，您将获得卡号、有效期、CVV，以及用于后续服务额度增加的订单编号和服务访问码。

服务网站：<https://service-delivery-site.guojiachor.workers.dev>

我们的重点不是一次性支付，而是为需要持续使用同一线上服务的用户提供更稳定、更易管理的支付方式。

## 核心优势：长期有效，持续可用

卡片采用长期有效的额度设置，并在首次成功交易后绑定至对应商户。首次使用时，您可以选择任意符合规则且接受该卡的商户完成消费；此后，只要卡片保持正常状态、服务额度充足且符合平台规则，您可以持续用于该同一商户的后续服务支付，无需为同一服务频繁更换支付卡。

长期使用带来的价值：

- 持续服务：适合需要按月或按周期续费的固定线上服务。
- 额度可管理：可通过订单编号和服务访问码增加服务额度。
- 使用范围更清晰：卡片绑定至同一商户，减少被用于其他商户的风险。
- 交付信息完整：订单完成后提供卡号、有效期和 CVV，便于妥善保存和后续使用。

## 商户绑定卡的适用范围

商户绑定卡适合在同一线上商户持续使用。首次成功交易后，卡片通常会锁定至该商户；每张卡只能绑定一个商户。

如需在另一个商户消费，需重新购买一张新卡，并使用新卡在该商户完成首次交易。

因此，本服务不适合以下场景：

- 在多个不同商户之间切换付款。
- 现金提取、转账或类似现金等价用途。
- 需要频繁变更支付商户的短期使用场景。

首次使用前，请确认目标商户和服务用途。商户绑定后通常无法改为其他商户。

## 重要保存信息

订单完成后，请立即、安全地保存以下内容：

- 卡号（账号）
- 有效期
- CVV
- 订单编号
- 服务访问码

其中，订单编号和服务访问码是增加服务额度的唯一凭证。请勿向他人透露，也请避免将卡片信息发送至公开聊天、邮件或不受信任的平台。

## 每月限量发售

为保证交付质量、额度管理和用户支持，本服务采用**每月限量发售**方式。可售数量会根据当月服务容量动态调整；额度售罄后，将在下一发售周期恢复。
