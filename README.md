# NORTHLINE 服务介绍

## 面向长期服务支付的美国本地虚拟卡

NORTHLINE 提供用于固定线上服务支付的美国本地商户绑定虚拟卡。完成订单后，您将获得卡号、有效期、CVV，以及用于后续服务额度增加的订单编号和服务访问码。

服务网站：<https://service-delivery-site.guojiachor.workers.dev>

我们的重点不是一次性支付，而是为需要持续使用同一线上服务的用户提供更稳定、更易管理的支付方式。

## 核心优势：长期有效，持续可用

卡片采用长期有效的额度设置，并在首次成功交易后绑定至对应商户。首次使用时，您可以选择任意符合规则且接受该卡的商户完成消费；此后，只要卡片保持正常状态、服务额度充足且符合平台规则，您可以持续用于该同一商户的后续服务支付，无需为同一服务频繁更换支付卡。

长期使用带来的价值：

- 持续服务：适合需要按月或按周期续费的固定线上服务。
- 额度可管理：可通过订单编号和服务访问码增加服务额度。
- 使用范围更清晰：卡片绑定至同一商户，减少被用于其他商户的风险。
- 交付信息完整：订单完成后提供卡号、有效期和 CVV，便于妥善保存和后续使用。

## 商户绑定卡的适用范围

商户绑定卡适合在同一线上商户持续使用。首次成功交易后，卡片通常会锁定至该商户；每张卡只能绑定一个商户。

如需在另一个商户消费，需重新购买一张新卡，并使用新卡在该商户完成首次交易。

因此，本服务不适合以下场景：

- 在多个不同商户之间切换付款。
- 现金提取、转账或类似现金等价用途。
- 需要频繁变更支付商户的短期使用场景。

首次使用前，请确认目标商户和服务用途。商户绑定后通常无法改为其他商户。

## 使用与充值教程

### 1. 完成购买并保存交付信息

访问 [NORTHLINE 服务网站](https://service-delivery-site.guojiachor.workers.dev)，选择“购买服务”并在 Stripe 托管结账页完成付款。

支付确认后，订单完成页会显示本次交付信息。请立即保存卡号（账号）、有效期、CVV、订单编号和服务访问码。关闭页面前确认已完整保存；这些信息不会通过公开渠道重复发送。

### 2. 首次使用并绑定商户

在您计划长期使用的线上商户处，填写交付的卡号、有效期和 CVV 完成首次交易。首次成功交易后，该卡将绑定至这个商户。

请在首次付款前确认商户选择正确。若需要在其他商户消费，请购买一张新卡；原卡不能用于新的商户。

### 3. 增加服务额度

当卡片额度不足时，访问 [服务额度增加页面](https://service-delivery-site.guojiachor.workers.dev/topup.html)。

1. 输入订单编号和服务访问码，查询当前服务额度和使用情况。
2. 选择需要增加的额度档位。
3. 跳转至 Stripe 托管结账页完成付款。
4. 返回成功页并等待状态显示完成；系统会将新额度更新至已绑定的卡片。

订单编号和服务访问码是增加额度的唯一凭证。输入错误、丢失凭证或在非本站页面付款，均无法关联至您的卡片。

### 4. 查看额度与交易

在服务额度增加页面输入同一组订单编号和服务访问码，可以查看总额度、已使用额度、待处理金额和近期交易。请以商户最终结算状态为准。

## 重要保存信息

订单完成后，请立即、安全地保存以下内容：

- 卡号（账号）
- 有效期
- CVV
- 订单编号
- 服务访问码

其中，订单编号和服务访问码是增加服务额度的唯一凭证。请勿向他人透露，也请避免将卡片信息发送至公开聊天、邮件或不受信任的平台。

## 每月限量发售

为保证交付质量、额度管理和用户支持，本服务采用**每月限量发售**方式。可售数量会根据当月服务容量动态调整；额度售罄后，将在下一发售周期恢复。
